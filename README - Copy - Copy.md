# ✨ Taskora — Smart Task Manager

> **Plan it. Track it. Crush it.**

Taskora is a modern, responsive To-Do List web application built using **HTML5, CSS3, and JavaScript**.

The project demonstrates client-side JavaScript logic, CRUD operations, state management, dynamic DOM manipulation, event delegation, filtering, searching, and persistent data storage using LocalStorage.

---

## 🚀 Features

### 📌 Task Management
- Create new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Mark completed tasks as active again
- Assign task priorities

### 🔎 Search & Filtering
- View all tasks
- View active tasks
- View completed tasks
- Search tasks instantly
- Clear all completed tasks

### 💾 Data Persistence
Tasks are stored using the browser's **LocalStorage API**, allowing task data to remain available after refreshing or reopening the page.

### 📊 Live Statistics
The dashboard dynamically displays:

- Total tasks
- Active tasks
- Completed tasks
- Completion percentage
- Filter counts

### 🎨 Modern UI
- Premium dark interface
- Glassmorphism cards
- Animated gradient effects
- Responsive layout
- Hover animations
- Priority indicators
- Empty-state design
- Mobile-friendly interface

### ♿ Accessibility
- Semantic HTML
- ARIA labels
- Keyboard-friendly controls
- Visible focus states
- Reduced-motion support
